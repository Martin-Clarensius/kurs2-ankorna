## Kommunikation
- Kanal: Slack (lärarfrågor) / Discord (allt annat)
- Vi svarar inom: 2 timmar under lektionstid
- Frågor och problem tas upp direkt i kanalen

## Arbetssätt
- Vi delar upp uppgifterna och skriver vem som gör vad
- Vi hjälper varandra om någon fastnar
- Vi har en avstämmning med teamet vid start och slut. 

## Git-regler
- Ingen push direkt till `main`
- Alla jobbar i en egen gren (t.ex. `namn-uppgift`)
- Ändringar går in via Pull Request och granskas av minst en annan
- Commit-meddelanden är korta och beskriver vad som ändrats
- Inga nycklar, lösenord eller stora pcap-filer i repot

## Möten och närvaro
- Vi kommer i tid och meddelar om vi är sena eller borta

## Konflikter
- Vi pratar öppet och respektfullt
- Går det inte att lösa tar vi hjälp av läraren

## Beslut
- Vi bestämmer tillsammans. Vid oenighet röstar vi.
